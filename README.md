# 🎵 Data-Analytics-for-a-Global-Digital-Music-Store
This project explores various business insights from a digital music store using SQL queries. The goal is to analyze customer behavior, sales data, and genre preferences to help the company improve marketing strategies, identify top customers, and optimize revenue.

## 🧠 Overview  
This project involves analyzing a fictional music streaming database to uncover business insights using SQL. The analysis focuses on key areas such as customer behavior, sales trends, and music genre popularity. It is an opportunity to apply SQL skills including `JOIN`s, `GROUP BY`, filtering, sorting, Common Table Expressions (CTEs), and window functions to solve real-world business problems.

---

## 🎯 Objectives  
- Answer key business questions using structured SQL queries.  
- Derive insights related to customer spending patterns, top cities for events, and genre popularity by country.  
- Practice writing clean, modular, and well-documented SQL code.  
- Demonstrate proficiency in intermediate to advanced SQL techniques.

---

## 📂 Dataset  
- **Source:** Provided by the internship company (via Google Drive)  
- **Structure:** Multiple tables including customers, invoices, invoice_items, tracks, albums, genres, and employees  
- **Type:** Simulated streaming and purchase data for a music company  

---

## 🛠️ Tools & Technologies  
- PostgreSQL (querying and analysis)

---

## 🔍 Methodology  
1. **Step-by-Step Querying:**  
   Queries were written and tested in a logical order to build up insights incrementally.

2. **Use of CTEs & Window Functions:**  
   Applied CTEs to simplify multi-step queries and window functions for ranking and cumulative analysis.

3. **Testing & Validation:**  
   Queries were tested using sample data to ensure correctness and accuracy.

4. **Documentation:**  
   Inline comments were added to explain logic, especially in complex query segments.

---

## 📌 Key Insights & Outcomes  
- 🏙️ **Best City for Events:** Identified the city with the highest number of high-value customers.  
- 👤 **Top Customers:** Ranked customers based on their total spending across all purchases.  
- 🎶 **Popular Genres by Country:** Mapped most-streamed or purchased genres by customer region.  
- 📈 **Sales Trends:** Analyzed invoice data to understand monthly and regional sales trends.  
- 🧾 **Customer Retention Indicators:** Used invoice history to highlight repeat customers.
